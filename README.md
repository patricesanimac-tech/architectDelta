# architectDelta

Documentation pour architecture.

## Agent TOGAF

Le dépôt fournit une définition minimale d'un agent d'architecture TOGAF dans le fichier `togaf-architecture-agent.json`.

### Objectif

Cet agent aide à :
- cadrer une initiative d'architecture d'entreprise ;
- structurer l'analyse selon les phases ADM de TOGAF ;
- produire une architecture cible, une analyse d'écarts et une roadmap de migration.

### Entrées attendues

- contexte métier et stratégique ;
- périmètre de l'initiative ;
- contraintes techniques, réglementaires et budgétaires ;
- architecture existante ;
- parties prenantes et attentes.

### Résultats attendus

- vision d'architecture ;
- architecture cible métier, applicative, données et technologique ;
- recommandations priorisées ;
- plan de migration ;
- risques et décisions à arbitrer.
